Privacy policy: Cartoozler uploader

Last updated: 1 November 2026

Cartoozler uploader is a private tool used only by the owner of the Cartoozler YouTube channel to upload the channel's own films. It uses YouTube API Services.

What it accesses

With the channel owner's permission, it uses the YouTube Data API to upload videos, set their titles, descriptions, tags, thumbnails, subtitles and playlists, and read the channel's own name and upload status. It does not read, collect or share data about any other person.

Where data is kept

The sign-in token is stored only on the channel owner's own computer. Nothing is sold, shared or sent to anyone other than Google/YouTube.

Revoking access

Access can be removed at any time in the Google account's security settings: myaccount.google.com/permissions.

YouTube and Google

By using this tool, the channel owner agrees to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.
